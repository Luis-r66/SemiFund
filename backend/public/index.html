SemiFund

Tesorería clara para tu semillero

SemiFund es la aplicación Android para registrar integrantes, aportes, abonos y gastos de un semillero de investigación, con aprobación del tesorero y comprobantes adjuntos.

Esta dirección es la API del proyecto. La aplicación se distribuye como APK.
